## The review

> One star. He types on my keyboard all day, then acts shocked when I sit on it. I live here. He just pays the rent.

## How it works

`main.ts` (Node 22, TypeScript run as-is) writes exactly that one review line
to `/output/entry.txt` — a single line, 114 characters, no trailing newline.
It is fully self-contained: no network, no secrets, no reading git history.

```sh
node main.ts
cat /output/entry.txt
```
